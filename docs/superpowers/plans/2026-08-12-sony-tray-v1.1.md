## Protocol Cheat Sheet v1.1 additions (verified against libmdr source)

- **Power off:** send `24 03 01` (`POWER_SET_STATUS`, `PowerInquiredType::POWER_OFF=0x03`, `PowerOffSettingValue::USER_POWER_OFF=0x01`). Device ACKs then drops the link. Only offer when capability 0x23 announced.
- **Support functions:** send `06 00` (`CONNECT_GET_SUPPORT_FUNCTION`, FIXED_VALUE) → RET `07 00 count (fn:1 priority:1)×count`. Function ids (Table 1, from Sound Connect iOS 12.2.0):
  - Battery: single `0x20`, left/right `0x21`, cradle/case `0x22` (also `0x28/0x29/0x2A` "with threshold" variants — treat same as their base type for querying; RET layouts add a trailing threshold byte per battery, parse and ignore it).
  - Power off: `0x23`.
  - NC/AMB variant → NcAsm inquired type: `0x6B` → `0x17` (Dual NC switch + ASM seamless, the XM5 payload already implemented); `0x6D` → `0x19` (same payload + `noiseAdaptiveOnOff:1` + `noiseAdaptiveSensitivity:1` appended; parse RET/NTFY, send CHANGED with both = 0); `0x67` (and none of the above) → `0x22` (ASM_SEAMLESS: payload after base is `ambientSoundMode:1, level:1` — no NC/ASM mode byte; UI hides the NC chip, Off/Ambient only).
  - EQ present: any of `0x50` PRESET_EQ / `0x52` / `0x57`; absence hides the EQ section.
- **L/R battery RET** (`23 01 …`): `leftLevel:1 leftCharging:1 rightLevel:1 rightCharging:1`. **Cradle RET** (`23 02 …`): `level:1 charging:1`. NTFY ids `25 01` / `25 02` same layouts.
- **EQ 10-band devices:** RET/NTFY band count 10, wire offset +6 (user −6…+6), no Clear Bass. Set payload: `58 00 preset 0A (b1+6 … b10+6)`. (XM5-class = count 6, offset +10, Clear Bass first — unchanged.)
- Init order becomes: GetProtocolInfo (await RET) → GetSupportFunctions (await RET) → capability-driven queries (NC/AMB with chosen type; EQ status+param if EQ; battery queries for each announced type).

### Task 13: Custom app icon

**Files:** Create `src/SonyTray/Assets/app.ico` (generated), `tooling/make-icon.ps1` (the generator, committed for reproducibility); modify `SonyTray.csproj` (`<ApplicationIcon>Assets/app.ico</ApplicationIcon>`, `<Resource Include="Assets/app.ico"/>`), `FlyoutWindow` (window `Icon`), `TrayIconFactory` (same visual language at 32 px: rounded-square #1976D2→#0D47A1 vertical gradient, white headphone band+cups, status dot bottom-right LimeGreen/Gray).
**Icon generator (make-icon.ps1):** draw 256×256 Bitmap — rounded rect r=48 filled with LinearGradientBrush (#1976D2→#0D47A1), white headphone: `DrawArc(pen w=22, 48,52,160,120, 180,180)` headband, two `FillRoundedRect(40,140,52,76, r=18)` ear cups; save PNG to memory; wrap in ICO container (write 6-byte ICONDIR: 0,1,1; one 16-byte ICONDIRENTRY: w=0,h=0 (=256), colors 0, planes 1, bpp 32, size=pngBytes.Length, offset 22; then PNG bytes).
**Steps:** run generator → confirm `app.ico` valid (open via `[System.Drawing.Icon]::new(path)`) → csproj wiring → build → launch: exe shows icon in Explorer/taskbar, tray uses new runtime art → tests green → commit `feat: custom Sony Tray icon (exe, window, tray)`.
